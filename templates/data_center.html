Import Indian products

Fetch a small sample associated with India from Open Food Facts, normalize the fields, save the raw response locally, save a cleaned CSV, and import the products into SQLite.

Responsible API use: V2 intentionally retrieves a small page rather than bulk-downloading the database. Open Food Facts asks API clients to identify themselves with a User-Agent and to limit returned fields.

What V2 creates

  • data/raw/ — raw API JSON snapshots
  • data/processed/foodgrade_india_latest.csv — cleaned dataset
  • SQLite records — products ready for later analysis
  • Data-quality score — simple completeness indicator for each imported product
